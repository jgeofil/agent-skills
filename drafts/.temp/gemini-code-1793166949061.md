## 5. Mandatory End-to-End Completion Gate (No Spec-Only Halting)
Never conclude a project generation request after only writing component specs. Every initialized system MUST include:
1. **Synthesized & Sealed Component Cells:** Every spec in `specs/<cell>.spec.md` must be compiled into `dist/<cell>/` and sealed via `regen_guard.py seal <cell>`.
2. **Composition Root (`dist/main/`):** A dedicated entrypoint cell (`contracts/main_contract.*`, `specs/main.spec.md`, `dist/main/`) sealed with `regen_guard.py seal main --entrypoint` that wires all adapters and domain cells into an executable CLI/service with a `--dry-run` flag.
3. **Deployment Manifests (`deploy/`):** A production `Dockerfile` and `docker-compose.yml` (plus cloud-specific event trigger setup scripts if targeting serverless).
4. **Operational Runbook (`README.md`):** Root documentation specifying:
   - Pipeline architecture and cell wiring diagram
   - Required environment variables and minimum IAM permissions
   - Exact commands to run tests, dry-run locally, regenerate a cell, and deploy to production
