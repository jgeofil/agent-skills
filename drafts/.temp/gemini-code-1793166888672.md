# GCP Cloud Cost Control (`gcp-cloud-cost-control`)

Autonomous, Spec-First cost monitoring and automated kill-switch controller for Google Cloud Platform. Built using a 5-Layer Regenerative Architecture with committed `dist/` provenance locks (`.spec-lock.json`).

---

## 1. Pipeline Architecture
```text
[ GCP Cloud Billing / Compute API ]
               │
               ▼ (Injected Client Port)
    [ dist/cost_ingestor/ ]  ──► [ dist/cost_policy/ ]  ──► [ dist/cost_actuator/ ]
               ▲                          ▲                          ▲
               └─────────────────── [ dist/main/ ] ──────────────────┘
                            (Composition Root & CLI)
