## 2. Pipeline Orchestration Sequence
1. Parse environment variables (`GCP_PROJECT_ID`, `MONTHLY_BUDGET_USD`, `HARD_CAP_USD`, `ENFORCEMENT_MODE`) and CLI flags (`--once`, `--dry-run`, `--pubsub-payload`) into `RuntimeConfig`.
2. CLI `--dry-run` flag unconditionally overrides `ENFORCEMENT_MODE` to `"DRY_RUN"`.
3. Instantiate HTTP/GCP transport handle and invoke `dist.billing_ingestor` to fetch current spend and active compute/GPU inventory.
4. Pass the validated billing snapshot into pure domain cell `dist.policy_evaluator` to compute required mitigation actions.
5. If `enforcement_mode == "DRY_RUN"`, log the proposed mitigation actions as structured JSON to stdout and exit `0`.
6. Otherwise, pass approved actions to `dist.resource_actuator` to stop non-essential GCE/GKE/Vertex AI resources or detach billing.
