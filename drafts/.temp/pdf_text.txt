def sha256_manifest(paths: list[Path]) -> str:
hasher = hashlib.sha256()
for p in sorted(paths):
if p.is_file() and p.name != ".spec-lock.json" and "__pycache__" not in p.parts:

Detailed Breakdown of the Top 4 Upgrades
1. Phased Wavefront Execution (Fixing Multi-Cell Truncation)
When initializing a project with 3 or more cells, an LLM cannot reliably author all contracts, specs, property tests, implementations, Dockerfiles, and
documentation inside a single response window (~4,000 to 8,000 output tokens).
The Fix: Update SKILL.md to forbid monolithic single-turn project generation. Instead, mandate a 3-Wave Execution Protocol tracked via a
root ARCHITECTURE.md checklist:
Wave 1 (Architecture & Contracts): Generate ARCHITECTURE.md (defining the cell DAG), contracts/*, and specs/*. Verify
contracts pass pyright or tsc --noEmit.
Wave 2 (Cellular Compilation): Iterate cell-by-cell: generate tests/**/<cell>*, synthesize dist/<cell>/, run tests, and execute
regen_guard.py seal <cell>.
Wave 3 (Composition Root & Operational Envelope): Synthesize and seal dist/main/ (--entrypoint), write
deploy/Dockerfile and deploy/docker-compose.yml, and generate README.md.
2. Transitive AST Hashing & Two-Phase Locking in regen_guard.py
Currently, regen_guard.py has two subtle loopholes:
1. In your GCP Cost Control example, contracts/cost_actuator_contract.py imported MitigationAction from
contracts/cost_policy_contract.py. Because collect_upstream("cost_actuator") only hashes files with "cost_actuator"
in the filename, changing MitigationAction inside cost_policy_contract.py would not invalidate dist/cost_actuator/.speclock.json.
2. During the 2-strike repair loop, an agent might modify tests/ to make a failing test pass rather than fixing dist/<cell>/.
The Fix:
Transitive Contract Hashing: Walk the AST of contracts/<cell>*, tests/**/<cell>*, and dist/<cell>/* to resolve all
imported contracts.* modules and include their byte hashes in upstream_sha256.
Pre-Synthesis Test Freezing: Have regen_guard.py unlock <cell> record the upstream_sha256 (locking contracts/,
specs/, and tests/) before synthesis starts. When regen_guard.py seal <cell> runs after synthesis, abort if
upstream_sha256 changed during the synthesis/repair window. This mechanically prevents the agent from weakening tests to pass a
broken implementation.
3. Hermetic Context Compiler (scripts/pack_cell.py)
In interactive agent environments (Cursor, Claude Code, custom CLI agents), when you ask an agent to regenerate dist/cost_policy/, its
default tool-use reflex is to run cat dist/cost_policy/__init__.py to see what is currently there. Once the broken code enters the context
window, the model anchors on the existing implementation and patches it mentally rather than synthesizing fresh logic.
The Fix: Bundle a pack_cell.py <cell> command into regen_guard.py (python3 scripts/regen_guard.py prepare <cell>).
In a single atomic step, it:
1. Unlocks and deletes dist/<cell>/* so the old implementation physically cannot be read.
2. Computes and freezes the upstream_sha256 digest.
3. Bundles contracts/<cell>*, specs/<cell>.spec.md, and tests/**/<cell>* into .scratch/context_<cell>.md and
verifies the combined input is under 8,000 tokens.
4. Enforcing Property-Test Presence on Domain Cells
A spec-first architecture is only as strong as Layer 3 (tests/). If tests/property/test_<cell>.py contains only two hardcoded assert
statements, the LLM can synthesize a lookup table that passes the test suite while failing in production.

The Fix: Add a check in regen_guard.py seal <cell> (for domain cells) that scans tests/ for the target cell and verifies the presence
of property-based fuzzing markers (@given for Python Hypothesis or fc.assert / fc.property for TypeScript fast-check).

def resolve_transitive_contracts(seed_files: list[Path]) -> list[Path]:
"""
Fixed-point BFS traversal across Python AST and TypeScript ESM imports.
Any contract in 'contracts/' imported directly or transitively (e.g. A -> B -> C) is included.
"""
repo_root = Path.cwd().resolve()
visited: set[Path] = set()
discovered_contracts: set[Path] = set()
queue: deque[Path] = deque(p for p in seed_files if p.exists())
while queue:
current = queue.popleft()
if current in visited or not current.is_file():
continue
visited.add(current)
new_refs: list[Path] = []
if current.suffix == ".py":
new_refs.extend(extract_python_contract_candidates(current, repo_root))
elif current.suffix in TS_EXTS:
text = current.read_text(encoding="utf-8")
for spec in extract_ts_specifiers(text):
resolved = resolve_ts_module_path(current, spec, repo_root)
if resolved is not None and resolved.parts and resolved.parts[0] == "contracts":
new_refs.append(resolved)
for ref in new_refs:
if ref not in discovered_contracts:
discovered_contracts.add(ref)
if ref not in visited:
queue.append(ref)
return sorted(discovered_contracts)
def sha256_manifest(paths: list[Path]) -> str:
hasher = hashlib.sha256()
for p in sorted(set(paths)):
if p.is_file() and p.name != ".spec-lock.json" and "__pycache__" not in p.parts:
hasher.update(p.as_posix().encode("utf-8"))
hasher.update(b"\0")
hasher.update(p.read_bytes())
hasher.update(b"\0")
return hasher.hexdigest()
