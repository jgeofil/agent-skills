# Scene evaluation

Score each candidate from [[pairing]] against this list.

- Psychological leverage: forces a contradiction, secondary gain, or inhibition into contact
- Asymmetry: imbalance of desire, knowledge, control, or vulnerability
- Escalation: the same dynamic can intensify across encounters without a new plot device
- Resistance: yielding costs something
- Specificity: distinctive physical or verbal tells
- Sustainability: first discovery, power test, spillover, post-sex regulation, public risk — not one peak

Rank:

- High charge / high sustainability — core material
- High charge / single-use — climax only
- Medium — connective tissue
- Low — discard unless requested

Minimum for every ensemble: one through-line, 4–7 secondary seeds, and a note on how the dynamic evolves or refuses to.
